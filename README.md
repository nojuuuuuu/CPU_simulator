# CPU動作シミュレーター

CPUが命令を取り出し、デコードし、値を読み、演算し、保存して次へ進む流れを、1ステップずつ触って学べる日本語のWebアプリです。

## 主な機能

- PC、IR、Decoder、Registers、ALU、Memory間のデータ移動を可視化
- Step、Run／Pause、速度調整、Undo、Reset
- レジスタ、メモリ、PC、Assembly／16ビット命令の直接編集
- 足し算、メモリ、if、while、ログイン処理の学習用プリセット
- CPU部品とクロックに関する初心者向け補足

## 開発

Node.js 22.13以上を使用します。

```bash
npm ci
npm run dev
```

テストと本番ビルド:

```bash
npm test
npm run build
```

## 学習用CPUの仕様

値は8ビット（0〜255）、命令は16ビットです。命令アドレスは4ずつ進み、加減算は256で折り返します。実在CPUの厳密な再現ではなく、命令取得・デコード・実行・保存・分岐の基本を理解するためのモデルです。
